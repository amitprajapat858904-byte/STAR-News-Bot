Auto-AI News System Setup Guide

💡 यह सेटअप कैसे काम करेगा?

  • News Collection: Google News RSS Feed से ताज़ा हिंदी ख़बरें उठाएगा।
  • AI Summarization: Gemini AI खबर को 3-4 लाइन के आसान हिंदी संक्षेप में बदलेगा।
  • Firebase Push: जनरेटेड कंटेंट आपके Firebase Database में स्टोर होगा।
  • Cloud Automation: GitHub Actions बॉट हर 6 घंटे में इसे ऑटोमैटिक चलाएगा।

1. Gemini API Key (100% Free)

aistudio.google.com पर जाएं और "Get API Key" पर क्लिक करके अपनी फ्री चाबी लें।

2. auto_news.js कोड

अपने प्रोजेक्ट के मुख्य फोल्डर में auto_news.js फाइल रखें और उसमें सही API Key (बिना किसी newline/break के) दर्ज करें।
